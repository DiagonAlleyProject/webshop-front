## Pasos para arrancar a desarrollar con VITE

```sh
1- "npm create vite@latest ./ "(El "." se refiere al directorio actual)
```

```sh
2- Seleccionas la tecnología "React"
```

```sh
3- Seleccionas "JavaScript"
```

```sh
4- Seguir las instrucciones para empezar a desarrollar:

    npm install o npm i --> (instala todas las librerias y la carpeta de nodoles para que el proyecto pueda funcionar).

    npm run dev --> (me permite arrancar el servidor de desarrollo (del FRONTEND))
```

## Forma rápida para arrancar un proyecto VITE

```sh
npm create vite@latest ./ -- --template react && npm i && npm run dev
```

## Detener el servidor de desarrollo

Ctrl + c
